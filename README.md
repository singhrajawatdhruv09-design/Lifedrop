# LifeDrop - Blood Donation Camp Management System

A beginner-friendly front-end project made with HTML, CSS, and JavaScript.

## Features
- Donor registration
- Donation slot booking
- Basic eligibility questionnaire
- Screening status management
- Queue management
- Donation status tracking
- Camp dashboard with live counts

## How to run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
   - Alternatively, use the Live Server extension in Visual Studio Code.

## Technologies
- HTML5
- CSS3
- JavaScript

## Note
This is a front-end demonstration project. Data is kept in browser memory and resets when the page is refreshed. The eligibility questionnaire is not a medical assessment; qualified medical staff must make all actual donation eligibility decisions.
